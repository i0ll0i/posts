# How to Install aaPanel on Linux

aaPanel is a free, open-source web-based control panel for managing Linux servers and websites. It provides a graphical interface for performing common server administration tasks without having to execute all operations manually from the command line.

aaPanel is primarily designed for Linux distributions and is suitable for both personal projects and web hosting environments. After installation, the panel can be accessed through a web browser, where administrators can configure the server and manage hosted applications from a single interface.

In the guide, we will look at how to install aaPanel on Linux.
